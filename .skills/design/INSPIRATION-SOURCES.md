# Fontes de inspiração visual

Ofereça essa lista pro cliente quando ele não tiver um site de
referência em mente (ver `.skills/onboarding/`, pergunta 3). São fontes
de navegação/curadoria, não substituem a decisão do cliente — ele
escolhe algo de lá, aí sim isso vira referência de verdade.

- **[Dribbble](https://dribbble.com)** — portfólio de designers, bom pra
  direção geral de estilo/paleta, menos pra estrutura de página real.
- **[RareUI](https://rareui.com)** — componentes e seções reais de
  produtos publicados, bom pra estrutura/composição de verdade.
- **[Land-book](https://land-book.com)** — banco de landing pages reais,
  filtrável por categoria/indústria.
- **[One Page Love](https://onepagelove.com)** — curadoria de páginas de
  uma tela só, bom pro caso comum deste framework (LP única).
- **[Mobbin](https://mobbin.com)** — foco em produto/app, útil se a
  página tiver componente de produto (não só marketing).
- **[Awwwards](https://awwwards.com)** — direção mais ousada/experimental
  — cuidado: nem tudo lá é "leve e performático", filtrar com isso em
  mente antes de levar como referência pro `pages-framework`.

Depois que o cliente escolher algo, salve o link ou uma imagem/screenshot
em `references/inspiration/` (ver `.skills/onboarding/`).
